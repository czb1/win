## 自动化覆盖

| 类别 | 主要检查 |
|---|---|
| 时间与地图 | 日夜边界、换日、基地四格、死单位、敌方与中立障碍、两格任务点 |
| 寻路与协同 | 原地目标、对角穿越、矿区邻格、无路可达、超时、同格冲突、交换位置 |
| 动作与经济约束 | 共享建造预算、武器上限、夜间禁止建造、满包采集、角色限制、缺字段 |
| 武器 | 武器键与炮手锁定、升级目标数、冷却、锥形、墙体遮挡、火箭溅射、电磁能量、缺射程 |
| 紧急物品 | 夜间治疗后不再占用炮手角色 |
| 任务与模型 | 严格 JSON、每日配额、任务期豁免、四回合 LLM／沙盒／答案闭环、跳回合旧结果丢弃 |
| 新闻与宝藏 | 无效新闻 JSON 限额重试、证据必填、用品重复数量、任务结束清理 |
| 状态与服务 | 建造失败退避、重复请求幂等、回合回退、换边隔离、空队、错误 JSON 恢复、决策异常兜底 |

原始测试输出保存在 `docs/test-output.txt`。其中故意发送 `{}` 的异常兜底测试产生 `KeyError: roundNo` 日志，此日志是预期测试过程；该用例验证服务仍返回完整空响应并继续工作。

## 复现命令

在项目根目录执行：

```bash
python3 -m unittest discover -s tests -v
python3 tools/replay.py examples/request.json
bash run.sh 8080
```

另开终端：

```bash
curl http://127.0.0.1:8080/healthz
curl -X POST http://127.0.0.1:8080/ -H 'Content-Type: application/json' --data-binary @examples/request.json
```
