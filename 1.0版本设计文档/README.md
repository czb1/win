# 1.0 版本设计文档（历史归档）

本目录由原 `docs/` 整体迁入，保留初赛阶段的实现设计、变更记录、测试报告和验证数据。它记录历史实现与历史结果，不作为 v2.0 / 32进16 的规则或适配完成证明。

| 文档 | 内容 |
|---|---|
| [战斗](战斗.md) | 历史武器策略、阵营隔离、操控者调度及验证 |
| [经济](经济.md) | 历史采矿、交易、采购、升级和资源调度 |
| [防御](防御.md) | 历史布局、围墙、炮台、补洞、修墙和回防 |
| [自进化](自进化.md) | 历史任务、模型、沙盒、记忆和宝藏处理 |
| [测试报告](测试报告.md) | 2026-09-14 的原始交付测试报告，不代表最新测试数量 |
| [原始测试输出](test-output.txt) | 上述测试报告关联的原 `docs/test-output.txt` |

同目录的其他 `*-benchmark.json`、`*-test-output.txt` 是历史回放数据和输出，随目录完整归档。历史正文中的目录名、提交号、执行命令和测试结果保留其当时口径；未随仓库保留的历史日志不补造。
