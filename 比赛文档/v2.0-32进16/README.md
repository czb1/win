## 阅读口径

- 游戏行为查任务书，字段和报文查接口文档；摘要和示例用于辅助理解。
- `destroy` 要求连续 4 个回合每回合执行，任一回合未执行即清零；不能理解为累计使用 4 次。
- 召唤令现在生成本方可控机器人，并要求 `targetPos`；不能沿用初赛的“增加对方浪潮”语义。
- 当前发布版本从 `v2.0.0` 起编号。本次整理未修改游戏实现，文档版本和包版本不代表新赛制功能已经适配或完成实战验证。
- 历史资料见 [v1.0 初赛比赛资料](../v1.0-初赛/README.md)，历史实现和测试见 [1.0 版本设计文档](../../1.0版本设计文档/README.md)。

## 原文待确认事项

1. 任务书 §4.5.4 第 6 条写到第二格碰撞时“第1格移动有效，整体停留在第2格”，实际停留位置存在歧义。原文保留，驾驶寻路适配前需向比赛方核实。
2. 任务书第八章列出四类异常，但后面的注释仍写“上述三类”。原文保留，异常计数口径需要结合完整规范及比赛方说明确认。
3. 任务书 §4.5.4 第 3 条将攻击路径写为两个坐标中心之间的直线，图注称红色为主动攻击的角色；直射起点究竟是武器格还是操控者格，需要比赛方或官方判题器确认。当前默认保留武器格起点，新增 `projectile_origin` 配置供确认后切换；射程和加特林90°锥形仍按武器格校验。
4. 同节没有明确枚举人物是否阻断直射弹道，也未文字规定擦过格子角点时的碰撞口径。角色移动障碍清单不能直接作为弹道规则证明。当前保留人物阻挡与旧直线遍历方式，新增 `projectile_characters_block` 配置；关闭人物弹道阻挡不会改变移动占位或机器人碰撞结算。第98～100回合节选已复现原策略因基地与炮手遮挡而不发攻击指令，但这不是官方结算规则的实战证明。

发现规范间的其他冲突时，记录来源与待确认问题，不自行改写任务书或接口原文。
