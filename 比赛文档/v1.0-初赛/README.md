# v1.0 初赛比赛资料（历史归档）

本目录保留初赛的任务书、接口文档和原始示例。当前比赛已进入 **v2.0 / 32进16**，后续规则和接口以 [v2.0 比赛资料](../v2.0-32进16/README.md) 为依据。

| 文件 | 用途 |
|---|---|
| [《未来战争》v1.0 任务书](《未来战争》v1.0%20任务书.md) | 初赛游戏规则、任务与积分规则 |
| [接口文档 v1.0](接口文档v1.0.md) | 初赛请求、响应和动作字段 |
| [request.txt](request.txt) | 初赛原始请求示例 |
| [response.txt](response.txt) | 初赛动作变体示例，包含重复角色 ID，不能直接当作单回合响应 |

文件正文与原始示例保持不变。v1.0 的角色属性、物品价格、召唤令语义和错误处理等不能直接用于当前赛制。

初赛实现和验证记录见 [1.0 版本设计文档](../../1.0版本设计文档/README.md)。仓库根目录的 `examples/` 是现有程序回放和测试使用的 v1.0 派生样例，继续保留原位置。
