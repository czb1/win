# 一、背景信息

- 云核心网编程大赛是面向云核心网研发管理部全员举办的一年一度大型软件竞赛，今年是云核心网第十届编程大赛。

- 在编程大赛的舞台，参赛人员可充分展示软件设计与编程能力，享受编码解题的乐趣，感受软件改变世界的魅力。

# 二、参赛要求

- 参赛组队要求：每队队员人数不超过3人。


# 三、游戏概述

- 游戏背景：2035年AI拥有自主意识，彻底不受人类控制，AI控制机器人在黑夜大举入侵人类村庄，两个参赛玩家扮演人类一方，在仅剩的两处人类根据地建造武器工事来抵御机器人的进攻浪潮，并存活下来。
- 每场比赛由两支参赛队伍同台竞技，无先后手区分。
- 两个玩家的基地分别在地图的左上和右下区域，玩家需要控制角色，在白天采集、建造、做任务来升级防御工事，晚上通过防御工事抵御机器人或对面玩家的进攻，直到双方玩家基地均被毁或坚持10天（1300回合）为止，游戏结束。
- 每场比赛进行两轮，分为上半场和下半场，下半场双方互换位置。

## 4\.2 时间单位

- 游戏以回合为核心调度单位，每一回合同时调度双方所有角色执行操作。
- 游戏世界观中以天为单位，一天分昼夜，白天=70回合，晚上=60回合。
- 单场比赛最大回合数为1300回合（10天），达到上限则比赛自动结束。

## 4.3 局部视野

- 己方所有单位（武器工事、基地、围墙、角色）的视野距离均为4。处于己方视野范围内的敌方单位可见，超出视野范围则不可见；机器人为全图可见。

- 己方所有单位视野全局共享；敌方基地、围墙为全局可见单位，不受视野距离限制。

4. 加特林炮台、火箭发射台经过升级可攻击多个目标，需要传多个攻击位置；电磁狙击炮只能攻击一个目标。

   - **加特林炮台**：加特林的多个攻击目标须落在同一 90° 锥形内（任意两个目标相对加特林的方向夹角 ≤ 90°，否则整次攻击非法）。每颗子弹沿自身落点的弹道飞行，命中该弹道上最近的一台机器人即消耗，造成 10 伤害/颗。

   - **电磁狙击炮**：玩家提供 1 个攻击目标。升级能够增加电磁能量。电磁能量沿弹道穿透：路径上每只存活机器人受 min(剩余能量, 该机器人当前血量) 伤害，能量按造成的伤害量扣减；能量耗尽或到达终点即止。

   - **火箭发射台**：每枚导弹中心伤害固定 20；落点周围 8 格溅射是中心伤害的一半；多枚导弹落点重叠时伤害叠加。发射后进入 3 回合冷却空窗。


5. 移动碰撞：角色移动在以下场景会触发碰撞，导致移动受阻
   - **碰撞触发条件**：① 目标点受阻：目标位置存在障碍物，或被本回合未移动的其他角色、机器人占据；② 目标点争夺：与其他角色或机器人预期移动至同一位置；③ 位置互换：两名角色预期互相移动至对方当前位置。

   - **碰撞结果**：与角色碰撞（含己方与敌方）：双方角色均中断移动，停留在碰撞前位置；与障碍物碰撞：仅己方移动角色中断移动，停留在碰撞前位置；与机器人碰撞：双方均中断移动，停留在碰撞前位置。

## 4.6 中立单位信息

整个世界的中立单位为小贩与武器商店；另有 4 个团队专属任务点（挑战者方 2 个、防守者方 2 个）。

### 4.6.1 小贩

玩家可通过将石头/铁/铜贩卖给小贩来赚取金币，而卖给小贩的矿石价格会随着世界新闻的内容而发生变化。

### 4.6.2 任务点

地图上有 4 个团队专属任务点。双方各占据2个，分别是任务点1与任务点2。其中任务点2占据两格，开拓者处于任一格即可领取任务，任务点有阵营区分，仅对本队开拓者开放；在敌方任务点执行任务无效。

2. 民间传闻：该世界中民间流传的一些传闻，玩家需要根据传闻来获取宝藏，详见第五章《任务》5.2章节。

# 五、任务

双方有3类任务，通过2种方式获取：

| 任务类型   | 通道     | 交互方式       |
| ---------- | -------- | -------------- |
| 推理类     | 世界新闻 | 新闻被动获取   |
| 长上下文类 | 世界新闻 | 新闻被动获取   |
| 自进化类   | 任务点   | 开拓者主动领取 |

其中经任务点领取的自进化类任务，每个任务点的任务总数有上限，在任务执行结束后，再次接取任务需等待 30 个回合刷新时间，以下行为都会视为任务结束：

- 任务被完成。
- 从领取任务起开始计时，计数回合超过了任务超时回合数。
- 离开己方任务点周围一格内。
- 领取任务的开拓者死亡。

任务结束后，无论任务是否被完成，任务都会消失，并获得相应的积分和金币，积分计算方式参考第六章《积分规则》，金币计算方式为任务金币奖励*通过率。

## 5.1推理类

【官方消息】报导的突发事件会引起供需关系发生变化，进而影响玩家与小贩之间的交易价格。

**示例：**

```
【官方消息】：
"矿业管理局紧急通报：北部铁矿区昨夜发生严重矿井塌方事故，主巷道结构受损，部分作业面被掩埋。安全监察部门已下达通知：为保障矿工安全，矿区将于明日全面停工，进行巷道加固和主矿脉修复。矿区领班表示：'今天浅层矿面还能抢采一些，明天的全面停工不可避免。'工程队评估：类似规模的塌方事故，修复工程通常需要2天左右才能完成并恢复开采。"
```

对游戏影响：

- 当天：铁矿采集不受影响。
- 明天+后天：铁矿无法采集，无法产出铁资源，同时由于铁的稀缺，小贩回收铁的价格上涨。
- 大后天及之后：铁矿恢复可采集，小贩回收铁的价格恢复到原来的价格。

## 5.2 长上下文类

【民间传闻】记录着市井消息，玩家需要控制开拓者收集关键信息，携带相关物品，前往祭坛召唤宝藏，获取祭坛宝藏。

**示例：**

```
DAY1: 【民间传闻】：情报1
DAY2: 【民间传闻】：情报2
...
DAYN：【民间传闻】：情报N
```

玩家需要根据情报1~情报N消息，找到关键信息，携带相关物品，前往祭坛召唤宝藏，获取祭坛宝藏，宝藏藏有大量积分与金币。

注意：

- 一张地图宝藏只有一个，成功开启后，后续继续开启则不会获得宝藏奖励。
- 宝藏需要开拓者通过召唤宝藏动作开启。

# 六、积分规则

$$\text{总积分} = score_1 + score_2 + score_3$$

**$score_1$ — 任务完成积分（任务完成时）**：

$$score_1 = \text{任务积分奖励} + 5 \times \frac{\text{任务标准回合数}}{\text{实际完成回合} - \text{接取回合}}$$

> 标准回合数 = 任务超时回合数

**$score_1$ — 部分完成积分（任务部分完成时）**：

$$score_1 = \text{任务积分奖励} \times \text{通过率}$$

> 通过率 =  回答正确字段个数 / 全量字段个数

**$score_2$ — 作战击杀积分**：

$$score_2 = \sum (\text{机器人击杀数} \times \text{机器人积分})$$，各机器人击杀积分详见4.7.2节

**$score_3$ — 生存天数积分**：

$$score_3 = \sum_{day=1}^{10} 10 \times day \times \text{存活系数}$$，其中存活系数 = 1（基地未被摧毁），= 0（基地被摧毁当天及之后）

# 七、胜负判定

1. 结束判定
   - 比赛双方异常响应均达到5次。
   - 1300个回合全部结束。

   - 双方基地均被完全摧毁。
2. 胜负判定
   - 每局比赛分为上半场和下半场，每半场换边对战，均获得胜利的一方为最终胜利方，双方均获得一场胜利则按照上半场和下半场两场得分总和进行比较，得分高的为胜利方，得分相同为平局。
   - 每半场对战，若双方基地在同一回合被同时摧毁以及积分相同，则为平局，否则根据第六章《积分规则》计算积分，积分数高的一方获胜；若双方基地在不同回合先后被摧毁，则先被摧毁的一方判负、另一方获胜。若半场游戏结束后双方基地均未被摧毁，则积分高者获胜。
3. 总积分判定
   - 胜一局积3分，平局双方各积1分，失败积0分。

# 八、异常处理

异常响应特指参赛代码触发的异常，包含以下三类：

1. 请求响应超时：建立连接过程超过10秒判超时；连接建立并发送请求后，5秒内未收到响应判超时。

2. 响应格式错误：返回数据格式不符合《参赛接口文档规范》。

3. 指令错误：发送指令标识无法识别、指令非法。

异常处理机制：

- 单队异常响应累计达到5次，后续回合不再调度该队伍代码，直至比赛结束。

- 参赛代码异常退出后，不再被拉起。

注：为避免歧义，明确以下两层口径：

- **异常**：仅当参赛代码出现上述三类情形之一时计为一次异常。其中"指令错误"特指指令字段缺失或指令无法被识别的情形，例如 `move`/`attack` 缺少 `targetPos`、`use` 眩晕法宝/范围炸弹未指定 `targetPos`、动作码非法等。
- **指令执行失败**：指令本身合法、字段完整且可被识别，但因游戏规则在执行时未能生效的情形，例如移动发生碰撞、攻击落点无目标等。此时仅该条指令标记为无效并跳过，不计入队伍异常次数。
