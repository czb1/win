# 防御模块设计

本文是防御模块唯一的长期设计文档。以后基地布局、建墙、炮塔位置、通路、回防和应急物品的变更都直接更新本文，不新建设计文档。

## 目标与边界

- 优先形成连续迎敌面，同时保留采矿、购物、接任务和炮塔操控所需的通路。
- 防线不能只以“墙数量”衡量，必须同时检查缺口、建成顺序、内圈连通和炮塔可操作性。
- 武器如何选择目标归入战斗模块；资源获取与采购顺序归入经济模块。

## 当前策略

- 默认外围按基地完整 2×2 占地向外扩展，迎敌面先从中心向两端铺设，再延伸上下侧翼，最后处理背侧。
- 背敌侧保留两格运输通道；这是明确取舍，不宣称完全封闭。
- 默认炮塔集中在迎敌侧并保留独立操控格；连续墙方案默认配合可越墙的火箭，避免直射武器被己方墙遮挡。
- 建造前验证基地、炮塔、商店、任务点和既有矿区的可达性；同回合新墙也进入后续工人的占位快照。
- 空闲角色会让出规划墙位；失败建造格进入退避，避免重复卡在同一位置。
- 临近夜晚优先用已有材料完成可建墙位并回防，不为了凑批次滞留远端。

## 关键设定与原因

| 设定 | 当前值或规则 | 原因 |
|---|---|---|
| 默认外围 | 20 格候选，背侧保留两格通道 | 在连续防线与外出物流之间取平衡 |
| 默认墙位 | 18 格 | 去除两格明确运输入口，不再为直射炮额外挖迎敌面射击口 |
| 默认炮塔 | 三座火箭 | 连续墙会遮挡直射武器；火箭越墙能消除这一直接冲突 |
| 建造失败退避 | 20 回合 | 避免非法坐标、占位或规则差异导致持续重复失败 |
| 显式布局 | 用户坐标视为完整白名单 | 已确认的官方坐标应优先于 demo 推导，不擅自平移或删改 |

## 已知风险与验证

- 默认建造区仍需与正式判题器核对；显式坐标应作为比赛环境首选。
- 三火箭不是全局最优证明，冷却期和不同机器人组合仍需实战比较。
- 运输通道可能成为绕后入口；复杂地形也可能让保守连通性检查少建墙。
- 回归应覆盖四角基地、左右镜像、矩形边界、补洞顺序、双工人建造、完整内圈可达、三个独立操控位和夜间回防。
