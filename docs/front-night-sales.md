# 迎敌面、夜间采矿与每日一次卖矿

## 执行规则

- 默认蓝图只保留迎敌方向六格墙；靠地图边缘时裁掉越界格。左基地向右防守、右基地向左防守，仍使用完整 2×2 基地范围定位。显式 `wall_cells` 不被截断。已建的其他墙不会拆除。
- 施工阶段，携带石头且相邻迎敌面有缺口的工人先补洞，再购物或送升级券。保留石料预留、施工可达性与炮手回防路径检查。
- 黑夜逐回合检查可见机器人。基地没有临近威胁，工人也没有附近危险时，解除站岗并采矿；不必等天亮。采矿不要求当晚能出售，也不套用白天第 70 回合截止时间。
- 矿点与整条采矿路径避开可见机器人的攻击范围及两格缓冲。针对我方的远处机器人也会限制采矿往返预算，避免走出去后马上又被召回。接敌时根据回塔路程、攻击距离和余量提前回防。开拓者仍可保持炮位或执行原有任务策略。
- 每名工人、每个白天最多一次卖矿访问。卖矿通常在准备建设/购物之前集中进行；背包满或已无可采矿点时可提前使用当日这一次机会。不会因达到旧的 40/80 单位阈值，或刚好凑够某项升级费用而反复往返。
- 协议的 `sell` 一次只能卖一种资源，因此一批混合矿可能需要连续几个回合出售；这仍算一次访问。失败出售可在当前访问中重试。执行其他动作后不再重开卖矿访问，下一白天才重置。建墙预留石头不出售。
- 当日卖过之后的新矿与夜间采矿留到次日。白天继续采矿仍检查返程预算；背包满则停止采集，不额外前往商人。

以上策略均由程序状态与路径计算决定，不增加 LLM 调用或要求模型记住每日次数。状态按原有队伍/基地会话隔离；与其他会话记忆一样，进程重启后不保留当日卖矿记录。

## 验证

运行 `python -m unittest discover -s tests -v`。新增测试覆盖四角迎敌面、夜间采矿、怪物死亡后恢复采矿、威胁重新出现后开火、无炮台避险、路径避开攻击范围、满包夜间不卖、混合矿集中出售、同日禁止第二次出售、次日重置及失败重试。

原有开局经济回放与三天补墙回放继续检查首夜炮台、操作员就位、迎敌面完整性与动作合法性。旧测试中“继续扩建侧后方”和“攒够一项费用就立即卖矿”的断言已按本次策略调整。

离线回放不模拟完整机器人战斗或迷雾，仅用于验证调度、经济和动作约束。夜间安全判定依据当前可见信息，不能证明视野外没有机器人；尚无真实比赛胜率结论。
