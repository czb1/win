# 实战采购与自进化改进

基线：`fd6a70d`。此次直接修改比赛入口和策略实现，保留 Python 标准库依赖。没有官方判题器和实际失败任务的连续请求，所以区分源码能确认的问题、受控回放结果和仍需实战验证的部分。

## 物品、经济和升级

原实现让所有工人先建墙再购物，没有主动购买药品；任何人携带任意升级券都会阻止全队购买其他升级券。建造一直不能完成、券不再适用或背包满时，升级链路容易被阻断。这并非证明购买接口失效：原版在本次有限六面墙的回放中也能最终升级武器。

现在有可达矿区和小贩时，两名工人中保留一人负责收入，另一人继续补墙；仍可共同完成初始炮台。购买和已持有物品的使用优先于继续补墙。矿石以实际价格选择，不硬编码必须挖铜。

采购顺序：急救药剂、重伤基地升级回血、每人一瓶备用药、一级武器升二级、基地升二级、武器升三级、基地升三级，最后升级围墙；受损围墙可提前买修复包。药品每人最多持有一瓶；开拓者受伤时也会自行购买。药剂在白天适当提前使用；夜间保留紧急治疗，以及炮台空闲时就地使用物品的机会。

升级券按当前可用建筑和团队持券数量决定是否购买，不再被不相关的旧券整体阻塞；同回合购买、升级目标和修复目标有去重。背包满时先卖矿，购物检查可达路径和交付时间，并为尚未建好的炮台预留金币。资金不足时为下一阶段武器或基地升级存钱，不把零钱持续花在低优先级墙券上。失败购买退避五回合。携带修复包的工人会主动走向受损围墙使用。

没有为了丰富背包而购买宝藏未知材料、召唤令或昂贵范围道具。炸弹和眩晕道具已有持有物的使用策略继续有效；此次新增主动采购集中在升级、药剂和修复。

## 两路机器人隔离

`targetTeam` 是协议直接提供的目标阵营，优先级高于当前位置、距离或出生方向。只有威胁我方的机器人进入目标收益计算；对方一路单独进入射程时不会开火或消耗冷却。

除瞄准目标外，还检查物理命中：加特林最近阻挡机器人、电磁炮沿线实际耗能命中、火箭落点的完整 3×3 范围都不能帮助对手清兵。安全边缘落点可以继续伤害我方来敌。炸弹、眩晕也执行同样的阵营过滤。两路紧密混合且没有安全弹道时可能减少开火，这是避免帮助对手的明确取舍。

兼容缺失 `targetTeam` 的旧数据：双方基地都存在时，用离哪个基地更近来推断；信息不足时沿用防御行为。正式协议应直接提供该字段，不依赖左上/右下坐标硬编码。现有三火箭与连续防线布局仍保留，因为直射武器与连续墙的遮挡冲突有明确依据；未证明三火箭是所有波次下的最优配置。

## 降低自进化对模型能力的依赖

题目明确给出本地 `.md`、`.txt`、`.rst` 文档路径时，程序先通过官方沙盒读取，不消耗一次模型调用来编写读文件代码。没有明确路径时不猜接口，模型可用 `LIST .` 查看目录、`READ 路径` 读取文件。每页最多 6000 字符，附带下一页偏移，长行中间的信息可继续读取。

任务期间固定保留首份文档、最近文档页、最近执行代码及退出结果、最近提交反馈。无效格式重试不会把失败代码和 API 文档挤掉。相同任务点可以引用之前实际读到的文档；标注它们仅有成功读取的证据，以本题当前文档为准。带简短说明的单个 Python 代码块和外层文本代码围栏也可解析。

提示按当前状态只要求一步：查文档、修正报错、查询求解或修正提交。显式最终答案仍要求 `[exitCode:0]`、完整输出和 `FINAL_ANSWER` 标记，超时、异常和截断输出不会自动交卷。已有成功解法的保存门槛不降低，也不自动运行旧题参数或复制旧答案。

夜间不再仅因时刻切换取消任务。两名工人照常回防；开拓者在任务期限内、没有我方来敌威胁时留在任务点。威胁判断同时考虑机器人攻击距离、开拓者实际回程长度和 `return_margin`；出现威胁则回防，记录 `task_stop=defence_threat`，超期记录 `task_deadline`。默认 `task_min_rounds` 调为 12，新增 `task_danger_radius: 6` 作为最低预警距离。回程判断仍是距离启发式，不是官方机器人路径模拟。

`SDK/main3.py` 原本只是回传请求的占位 Flask 服务，此次转接到正式智能体，避免因入口不同而未运行优化代码。根目录 `run.sh` 和 `CoreGeek/main3.py` 均可继续使用。

## 验证与取舍

本地 Python 3.12.14，118 项测试通过；CI 继续使用比赛指定的 Python 3.11.10，未在本机运行该版本。完整输出见 [match-fixes-test-output.txt](match-fixes-test-output.txt)，回放原始结果见 [match-fixes-benchmark.json](match-fixes-benchmark.json)。

五天受控经济回放使用固定价格、无限矿藏、两名工人、三座初始一级火箭台和六个墙位，不含机器人战斗、真实模型、任务奖励或判分。

新策略更早投入初级火力、基地和补给，但后续三级升级略晚，额外购物及交付占用采矿时间，最终现金也更少。金币差异不能全部视为升级花费或效率损失，更不能据此宣称胜率更高。

旧有左右镜像首日建墙测试仍为 18 面墙、迎敌侧无缺格、零非法动作。740 机器人静态战斗回放 20 次，三座塔均能攻击，最慢约 50.25 ms；这不是最坏情况时限保证。

新增回归验证全部武器与等级的两路阵营隔离、直射阻挡、火箭安全溅射边缘、购物优先级、存钱、满包出售、修复交付、长期升级闭环、兼容入口，以及真实执行固定读文件工具的“读文档→读数据→提交答案”回合链。模型回复使用固定样例，验证状态机可靠性，不能代表实际弱模型的解题成功率。
