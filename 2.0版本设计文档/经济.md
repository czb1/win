# 经济模块设计（v2.0 / 32进16）

状态：需求与待办基线，尚未核验现有实现，待适配与验证。本次仅整理文档。

依据：[v2.0 任务书](../比赛文档/v2.0-32进16/《未来战争》v2.0%20任务书.md)、[v2.0 接口文档](../比赛文档/v2.0-32进16/《未来战争》v2.0%20接口文档.md)。历史实现见 [1.0 经济设计](../1.0版本设计文档/经济.md)。

## 目标与边界

梳理矿石、价格、采购与召唤使用的变化。建设与回防见防御模块，可控机器人攻击见战斗模块；本次不调整采购顺序和资金分配。

## 新规则与待适配事项

| 规则或接口变化 | 需要核对和适配的事项 |
|---|---|
| 矿区元素新增 `remain`，范围1～10，其他中立元素为null | 解析与选矿依据、耗尽后的目标失效处理 |
| 矿区按左下到右上的分界线分半区 | 核对矿区划分和刷新数据，不能使用基地朝向代替半区规则 |
| 捣乱鬼 `destroy` 连续4回合，每回合执行；未执行即清零 | 破坏目标、进度与中断；成功后该半区该类矿10回合不补刷 |
| 围墙修复包15，眩晕法宝与范围炸弹50，任务用品10 | 核对预算、采购门槛和历史成本记录；实际采购继续核对商店报文 |
| 四档召唤令价格15/20/70/120，生成本方可控机器人 | 不沿用初赛的增加对方浪潮语义；采购价值和使用时机待设计 |
| 召唤令 `use` 必须指定合法 `targetPos`，每天最多10张 | 位置限制、重复待生成位置、旁移和夜间统一生成的边界 |

## 关键设定与原因

- 批量卖矿、保留施工石料、升级券交付等1.0策略先保留为继承候选；新价格和矿区机制可能影响其门槛，需要逐项核验。
- 捣乱鬼无背包，不能套用工人的采矿、交易或物品运输职责。
- 破坏和抓捕的优先级尚未确定；本次不预设新角色策略，也不修改旧采购预算。

## 待验证

- `remain` 的矿区/非矿区解析与目标耗尽、刷新、半区冷却。
- `destroy` 连续执行、中断清零、被抓以及矿被采光。
- 新价格下的余额、库存、背包、购买数量与资源预留。
- 召唤位置合法性、物品退还、旁移、待生成位置去重与每日使用上限。
- 原批量卖矿和建设采购策略的回归；收益需后续真实对战验证。
