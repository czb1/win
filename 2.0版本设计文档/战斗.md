# 战斗模块设计（v2.0 / 32进16）

状态：已实现捣乱鬼白天破坏与夜间守口、开拓者三火箭轮射，以及满级防线后的BOSS召唤与薄弱点进攻；验证范围见变更记录。

依据：[v2.0 任务书](../比赛文档/v2.0-32进16/《未来战争》v2.0%20任务书.md)、[v2.0 接口文档](../比赛文档/v2.0-32进16/《未来战争》v2.0%20接口文档.md)。历史实现见 [1.0 战斗设计](../1.0版本设计文档/战斗.md)。

## 目标与边界

默认采用三座火箭：开拓者每晚在公共格按实际冷却轮流操作，每回合至多开火一座。工人继续安全采矿与守墙；捣乱鬼在唯一朝炮塔缺口守口承伤，有队友通行时侧移让路。附近威胁清除后满级火箭继续攻击敌方墙。按经济模块的防线、备包及可执行预算门槛消费余款，优先批量购买BOSS召唤令；召唤落点优先敌方背面薄弱入口，生成后的机器人朝敌方基地推进，逐回合先清除攻击路径上的最近敌方阻挡物。

## 关键设定与原因

- 继承1.0的火箭轮射、操控者分配和阵营隔离时，先核对四角色及新机器人集合，避免沿用“所有机器人均是系统浪潮”的假设。
- 新攻击数值以v2.0任务书为依据；接口中实际下发的状态与规范冲突时记录证据，不凭历史参数补造。
- 加特林伤害估算已按任务书 §4.5.4 调整为每颗25；排序使用当前血量，先检查射程、建筑阻挡、最近机器人命中及90°扇形约束。同回合已安排的伤害仅用于避免无效重复打击，不将被其他子弹覆盖的存活机器人当作已经消失的弹道障碍。
- 直射占位与移动占位分别维护；默认弹道起点为武器格，人物仍阻挡弹道。依据当回合目标评价相邻操控格，用投影位置计算换位后是否可命中，不修改原始地图观测；无有效弹道的固定格允许替换，有效固定格保持稳定。规则歧义及可配置边界见本阶段比赛资料说明。
- 三座火箭按平台实际冷却轮射，每回合最多由开拓者操控其中一座，不假设三炮能在同一回合由同一角色开火。捣乱鬼守口与通行细节见防御模块的最新记录；显式混合阵型保留已有加特林控制和弹道校验。
- 机器人召唤令采购以当回合存在存活敌方基地为前提；敌方基地全图可见，血量归零或从报文移除后立即停止所有等级采购、取消在途采购任务，并释放采购角色与金币预算。

### 2026-10-10 - 可控机器人原地多落点攻击与重复碰撞避让

- 策略：敌方基地占用四格，先检查机器人当前站位能否攻击其中任一格，原地存在本地模型允许的攻击时优先攻击基地；单条连线被挡不再等同整个基地无法攻击。基地没有可用落点时，检查朝基地各格连线上的最近敌方阻挡物，能原地清障则先清障，之后才接近或绕行。原来偏离进攻路线的弱墙不成为常规攻击目标。
- 设定：紧邻上回合的攻击明确合法时记住机器人、站位、目标和落点；仍满足当前射程、占位和失败记录检查时优先保留该落点。一个基地落点明确失败后，先在同一站位尝试其他可用格；所有可用格均失败或受阻后才换位。换位搜索也按全部基地格检验射界，并保留失败后优先接近目标的处理。记住合法落点只表示平台接受过指令，不表示命中或造成伤害。
- 设定：失败攻击关联当时连线上的占位，连线占位变化后解除该落点的旧失败限制；占位不变则不重试同一失败落点。移动后仍未到达的目标格按该机器人重复碰撞次数分别暂避4、8、16回合，16回合封顶，成功到达后清除累计次数；记录在机器人消失、换日或基地变更时清理。保留普通共享视野的历史炮塔证据、隐藏目标多站位失败绕行、人物与归属未知机器人的保守占位及单机器人单动作约束，不推测未观测单位已经死亡。
- 原因：本次上传的71～127回合决策中，31036提交37次攻击和20次移动；截至127回合的反馈实际覆盖71～126回合，其中7次攻击和7次移动返回false。100回合两台机器人分别位于 `(8,19)`、`(7,19)`，后者原来因只检查基地 `(9,21)` 的连线而改发移动。对这些坐标的局部复现中，本地模型允许对基地 `(9,22)` 的另一条攻击线。最初快照仅覆盖70～79回合；后来补充97～106回合后确认仍有不可见占位及会话记忆重置，具体见上条记录，不能认定该替代指令必然合法或有效，也不把整个晚上的移动都计为浪费。
- 经验教训：优化目标是减少本可攻击时的移动与反复碰撞，不能用攻击指令数量替代有效伤害。71～96回合连续清理历史炮塔的合法反馈不足以证明空打或炮塔血量；需结合目标再次可见、升级或死亡证据。官方文本仍未完整规定可控机器人攻击的角点与碰撞细节，本次沿用已有保守遍历，无法承诺所有真实判题器回合都命中或达到全局最优。
- 验证：新增13项快速状态／边界检查，覆盖四个基地落点、原地替换失败落点、部分友方／公共机器人／NPC／炮塔遮挡、合法落点保持、99～100回合坐标局部复现、替代落点的寻路站位、射路占位改变与不变、双轴镜像、重复碰撞延长避让、到达后清理和换日清理。保留旧隐藏炮塔与失败换位测试的原意，改为全部落点不可用时再换位。与未修改代码做同输入对照，单格失败场景及99～100回合坐标节选均从移动改为原地攻击。项目 `.venv/bin/python tools/run_checks.py` 同步最新main的基地被毁停止采购修复后，默认快速模式通过976项，失败／错误均为0，耗时38.90秒；本地只有Python 3.12.14，没有Python 3.11，远端既有CI使用3.11.10。省略10项仿真及独立策略基准，未执行真实判题器对战。

### 2026-10-10 - 机器人朝基地清障与失败换位

- 策略：按用户要求，以敌方基地为持续进攻方向，每回合重新检查机器人到基地占用格的路径。最近的敌方炮塔、围墙或角色挡住路径时先攻击该单位；超过射程则先接近，下一次观测再决定阻挡物是否仍在。不能按预计伤害提前越过活墙或炮塔，也不为远处、偏离当前进攻路径的弱墙改道。召唤位置继续使用背面薄弱入口排序。
- 设定：沿用现有 `line_cells` 的保守格子遍历，角点擦碰也纳入检查；人物阻挡是本次用户明确要求的机器人进攻策略，与炮台 `projectile_characters_block` 配置独立。机器人射程保留任务书的三格。友方单位、归属未知的公共机器人、矿石和NPC不成为攻击目标，改找可达且射界畅通的站位；无可达站位时保留路径受阻诊断。不可攻击障碍封住入口时允许通过其他墙位绕行清障。
- 设定：机器人模块独立记录曾实际观测的敌方炮塔，失去视野后保留其固定位置；明确死亡、重新进入普通己方共享视野却未出现、或基地变更时移除。历史人物位置不用于攻击。历史炮塔通过机器人专用目标列表参与本地校验，日志标记 `last_seen_building`，不改写当前敌方可见列表，不声称历史血量仍为当前血量。攻击是否合法与伤害／拆除是否成功仍须区分。
- 设定：同一隐藏炮塔在两个不同站位攻击均非法、且至少一次落在两格以内时，暂停把旧记录当成可攻击目标，保留其占位并尝试绕行；重新看见炮塔后恢复清障。此处理防止炮塔已不存在却仍持续攻击旧坐标，不把非法反馈视为确认死亡。
- 设定：只关联紧邻上一回合的机器人指令与反馈；明确 `false` 时禁止该机器人在相同站位重复攻击同一目标落点，重新寻找不同站位，该失败记录在机器人消失、换日或基地变更时清理。移动后位置未到达则暂避该落点四回合。机器人寻路目标必须有畅通射界并排除失败站位，避免简单重寻路仍返回“已在攻击位置”。
- 原因：所提供日志里三个BOSS在71～98回合分别连续28次攻击非法；其到基地连线经过历史炮塔 `(8,20)`／`(8,22)`，原分支只检查距离且不消费机器人攻击失败反馈。本次实现用户指定的清障方式，不能据此宣称已确认平台拒绝原因。
